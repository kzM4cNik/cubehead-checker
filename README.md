# CubeHead Checker

Окно CubeHead. Саму проверку jar делает локальный `Y-check.exe`, его окно не показывается. Y-check может сверять моды с Modrinth.

## Запуск из исходников

```bat
py -3 cubehead_checker.py
```

Нужен Python 3.12 и пакет `windnd` (перетаскивание jar).

## Что умеет

- **Scan** — папка, диск или один файл, выбранные в большом окне Browse.
- **Scan PC** — все локальные диски. Повторное нажатие останавливает проверку.
- Имя файла, id мода и строки внутри классов.
- **Bytecode Viewer** — список файлов в jar и строки выбранного класса.
- Отчёт на рабочий стол из меню шестерёнки.

Сигнатуры лежат в `signatures.json`.
